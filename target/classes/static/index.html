🌦 INMET — Estações Meteorológicas
🏛
API pública INMET — sem autenticação
Endpoint: GET https://apitempo.inmet.gov.br/ESTACAO/{inicio}/{fim}/{codEstacao}
Chamada direta do browser. Se CORS bloquear, use o trigger manual do backend abaixo.
A701 — São Paulo (Mirante) portal.inmet.gov.br para outros códigos
GETapitempo.inmet.gov.br/ESTACAO/{inicio}/{fim}/{codEstacao}
💡 Período máximo recomendado: 30 dias. Leituras horárias (HH00 UTC).
