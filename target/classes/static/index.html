NASA POWER — Dados Orbitais

fonte=NASA_POWER · parâmetros: ALLSKY_SFC_PAR_TOT, CLOUD_AMT, T2M · community=AG · scheduler: 06:00 diário
Scheduler NasaSyncScheduler executa automaticamente às 06:00 todo dia para todas as fazendas. Use o endpoint abaixo para sincronização manual.
POST/api/dados-orbitais/fazenda/{id}/sincronizar
🛰 Chama a NASA POWER API com as coordenadas da fazenda e persiste dados de irradiância PAR, temperatura e nebulosidade
GET/api/dados-orbitais/fazenda/{id}
GET/api/dados-orbitais/fazenda/{id}/ultimo
GET/api/dados-orbitais/fazenda/{id}/periodo
Teste direto — NASA POWER API pública
GETpower.larc.nasa.gov — chamada direta ao endpoint NASA
Chama diretamente a API da NASA com os parâmetros ALLSKY_SFC_PAR_TOT, CLOUD_AMT, T2M, RH2M

Open-Meteo Forecast — Tempo Real

fonte=OPEN_METEO · shortwave_radiation, cloud_cover, temp_2m, rh_2m · scheduler: a cada 15 min
Scheduler OpenMeteoSyncScheduler executa a cada 15 minutos para todas as fazendas. Faz upsert: atualiza se já existe OPEN_METEO para o dia, pula se outra fonte.
POST/api/dados-orbitais/open-meteo/fazenda/{id}/sincronizar
⚡ Busca previsão de 2 dias (shortwave_radiation, cloud_cover, temperature_2m, relative_humidity_2m) e salva médias diárias
📡 Dados no banco (fonte=OPEN_METEO)
Use os endpoints /api/dados-orbitais/fazenda/{id} e filtre por fonte=OPEN_METEO
Teste direto — Open-Meteo Forecast API pública
GETapi.open-meteo.com/v1/forecast — chamada direta
📚

ERA5 Archive — Carga Histórica

fonte=ERA5_ARCHIVE · dados horários 2020–2024 · idempotente: dias já existentes são ignorados · 1x execução
⚠ Operação longa — carrega ~5 anos de dados (1825 dias por fazenda). Execute por fazenda ou fora do horário de pico.
POST/api/dados-orbitais/era5/fazenda/{id}/carregar
Carga padrão 2020-01-01 → 2024-12-31. Idempotente — dias já existentes são ignorados silenciosamente.
POST/api/dados-orbitais/era5/fazenda/{id}/carregar/periodo
Período customizado — útil para carregar ano a ano em bases grandes
POST/api/dados-orbitais/era5/carregar-todas
⚠ Itera sobre TODAS as fazendas — operação muito longa. Use apenas para setup inicial.
Teste direto — Open-Meteo Archive API pública
GETarchive-api.open-meteo.com/v1/archive — chamada direta
⚡ Recomendado: testar período curto (7 dias) para validar a resposta antes da carga completa
